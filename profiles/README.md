# 本地候选人数据

这里的 `example_*.json` 是匿名示例，随源码仓库和绿色包分发。

上传简历的原文件另存在本机用户数据目录；提取文本、候选人画像、简历版本元数据和求职记录存入本机 SQLite。标准启动的数据目录是 `%LOCALAPPDATA%\RoleFlow\Data`，CLI 显式指定 `--data-root` 时使用该目录。云模型分析会收到经过本地联系方式处理的必要文本，“本地保存”不等于没有模型请求。

如需用旧版命令行 JSON 文件，可从示例复制一份并在扫描命令中通过 `--profile` 与 `--resume-versions` 指定。请勿把真实简历、求职记录或浏览器登录态提交到 Git。
