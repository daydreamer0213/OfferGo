# 今日任务平台范围展示计划

目标：今日任务直接展示当前平台搜索页的工作地点和已选条件，工作区操作归入上方 Edge 状态条。

1. 先补回归检查：BOSS 无 URL 城市参数但页面显示“广州”、智联未选地区、双平台组合、进行中的轮次保持原条件；页面不再输出占位的“继承模式”、两轮间隔和解释性文案。
2. 复用现有 BOSS 只读页面检查，把当前城市作为展示数据传给搜索条件预览；智联根据已读取的原生筛选标签展示“地区不限”或具体选择。不修改扫描范围和平台访问节奏。
3. 将“重新读取搜索条件”放在共用工作区状态条右侧，与现有工作区按钮同一尺寸和样式。找岗卡片只呈现平台、真实地点与筛选、关键词和今日进度，错误留在条件位置说明。
4. 跑相关快速与浏览器检查、完整离线门禁；安装独立验收版后在现有 Edge 中只读核对 BOSS、智联、双平台及深浅色布局。

外部通信和投递不在此计划内；正在进行的轮次继续使用创建时固定的条件。
