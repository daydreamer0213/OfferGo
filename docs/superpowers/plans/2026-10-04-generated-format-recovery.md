# 三模块生成格式衔接修复计划

用户已授权核实审查发现并直接修改。本计划只处理已在虚拟用户真实 Dashboard 路径复现的问题，沿用当前工作树与模块。

## 设计决定

- 面试复盘：模型说明明确 outline 是字符串数组；校验入口将字符串提纲作为单项数组处理，仍使用现有长度、题号及内容检查。空值、对象、非法题号等继续拒绝。
- 简历优化：建议编号属于程序内部标识，由 application 在模型输出恢复原文锚点后按顺序生成 S1、S2，再交原有严格校验。保留原文唯一性、证据、数字、职责与重叠检查；存储接口与既有草稿不变。
- 展示：参考简历和目标方向保留；模型提供方式移到默认收起的技术详情。修改说明显示普通顺序号，不修改数据中的编号和旧草稿表单键。
- 截图补充发现：深色模式下简历结论缺少背景覆盖，沿用已有重点区域的深色背景，并在现有 Edge 路径检查深浅主题的实际文字对比度。
- 不增加重试模型请求、外部平台操作、新依赖、数据库迁移或新的架构层。
