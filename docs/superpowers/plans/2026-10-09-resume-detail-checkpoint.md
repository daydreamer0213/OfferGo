# 恢复采集时保留可信详情

真实恢复任务中，同一岗位已保存的完整详情在重新采集卡片时被空卡片进度覆盖，直到后面的目标检查点才重新出现。如果期间再次中断，完整详情可能丢失，导致重复读取或无详情分析。

修复仅复用 BOSS adapter 现有缓存匹配逻辑：列表进度与后续详情循环采用同一张规范化卡片。仍核对标题、公司、地点、薪资、年限与学历，字段变化时拒绝旧详情。保留既有缓存期限、浏览器访问预算与节奏，不修改通用存储覆盖语义。

先扩展现有缓存回归，旧实现已确认失败于列表检查点的空详情；再抽取原有几行缓存合并逻辑供两处使用。检查正常缓存复用和卡片事实变更拒绝缓存，最后与其他验收修复一起执行完整门禁。
