# 完整 JD 工作判断：有限实施计划

依据同日 `2026-10-10-jd-work-selection-design.md`。有限实现已开始，生产 `src/tests` 正在接入和验证；现有五份工作文档的修改保留。所有私有和生成证据留 D 盘。已获准持续推进，不再为普通内部实现反复求许可。当前证据与未完成项见 `../reports/2026-10-10-jd-work-selection-implementation-checkpoint.md`。

## 1. 先锁定回归输入与实际配置

新增 `tests/job_work_matching_smoke.js`，使用虚拟材料，验证以下可观察行为：

1. 合法四档经过校验、分析组装、存储和读取仍是原四档；普通学制遗漏不会被程序压档。
2. 所有支持原句来自绑定来源；假引用、JD 当候选证据、重复引用和必要字段缺失失败。
3. 同一 JD 独立算法校招与社会后端招聘不会在扫描前被算法届别排除；全职目标与明确只有实习的岗位仍保留现有工作性质边界。
4. 明确城市排除、待刷新、资料不足时不请求模型，原因和待办保留。它们不是模型推荐或模型故障的替身。
5. 真实坏 JSON 解析路径只能有一次原响应反馈；第二次再失败保留失败；截断一次扩预算；中止/认证/额度不当格式恢复。并发岗位互不串反馈、预算和引用。
6. 已知输入数组的空回显允许清除，五字段完全不变；非空回显和未知字段不被吞掉。

不能用假模型预置档位证明模型理解学历或工作；真实效果证据来自已完成的实验。原始失败不能从统计分母删掉。

本次效果与普通 Edge 验收用开启思考/high。实现尊重保存的设置；推荐新默认开启，旧保存值不自动覆盖。关闭模式的四例已显示缺陷，不能继续扩大到生产后称效果一致。

## 2. 接入最小整体合同和适配器

文件：

- 新增 `src/core/job_work_matching.js`：冻结业务任务、五字段结构、无损短来源索引、通用空输入回显规范化、来源校验及一次恢复协调。合并实验原型，不把历史 C3–C11 文件链搬入产品。
- `src/adapters/models/structured.js`：新增完整工作匹配方法，直接读取完整输入，不拆职责/要求；保持其他模型任务行为。
- `src/adapters/models/openai_transport.js`：支持该方法的请求级零原生重试和预算；实际坏回复只附在内部错误用于本次恢复，不进入通用日志。避免修改共享实例全局属性。
- `src/core/llm_analyzer.js`、`src/core/model_contract.js`：接入新方法和缓存读取的原来源复核；禁止外层再追加一轮合同修复。

先验证以上回归，确认实际请求模式、温度/推理参数与生效配置一致，所有失败仍有明确状态。不会靠源码出现某个提示词判测试通过。

## 3. 修复前筛职责并接入分析主路径

文件：

- `src/core/job_eligibility.js`、`src/core/scoring.js`：把届别/学生身份等 JD 作用域条件留给所选工作方向，保留原事实和来源；不把它们作整份 JD 的预筛、100 分罚分或全局风险说明。复用原工作类型及用户/平台明确边界。
- `src/config.js`：新增 `whole_jd` 模式和新默认；显式 split/legacy 可用于兼容及回退。
- `src/core/job_analysis.js`：前筛结束后只对允许且完整的 JD 调用新方法。输入必须是完整同版本画像、确认卡、原 JD、实际有效偏好及当前日期。复用队列和缓存。
- `src/core/job_match_decision.js`：新结果只承接明确范围/刷新/完整性/失败边界，不经过旧矩阵和资格 unknown 封顶。旧模式算法留在明确兼容分支。
- `src/core/analysis_revision.js`：新任务/管道/决策版本、完整输入与实际推理配置进入缓存和陈旧判断。旧结果需刷新，不直接重算。
- `src/core/model_settings.js`：推荐批筛新配置开启思考；保留用户已保存选项，不用隐藏运行时强制开关。

新增与现有 `tests/job_eligibility_smoke.js`、`tests/analysis_application_smoke.js` 对应行为回归。旧算法测试显式使用旧模式，不把测试兼容当生产静默回退。

通过信号：独立后端能够到达模型；明确范围外岗位没有模型请求；普通遗漏不会程序降档；四档和失败进入正常队列保存；旧缓存不命中，新缓存能够复用，中断后按原任务续跑。

## 4. 补回绑定的完整简历

文件：`src/core/profile_schema.js`、`src/storage/candidate_store.js`。

仅解除证据原文复用普通 1000 字短字段函数造成的截断；仍使用已有简历准备、脱敏和输入大小限制。历史恢复先核对版本、确认卡、文档归属和哈希；非空且恰为同版本已脱敏全文前缀的旧证据也恢复。已有不同文字或用户修订不被覆盖。

回归包括：超过 1000 字且后半段有重要实际交付的同绑定材料；错误 profile、document、hash；脱敏失败；已有完整文字；用户修订。只通过绑定恢复原资料，不制造新经历。
