# 智联搜索页自动整理

目标：今日任务读取智联条件时自动准备搜索页；多个同窗搜索页按有效筛选条件数量保留最完整的一页，并关闭其余后台重复页。页面不再要求用户点击单独的“准备智联搜索页”。

1. 在 `tests/dashboard_zhaopin_smoke.js` 先覆盖缺失页自动准备、较完整页保留、完全相同页合并、页面实际选中条件较多时的选择，以及不同窗口和前台页不误关。
2. 在 `src/dashboard/server.js` 复用现有串行浏览器读队列和准备函数。读取条件先整理同窗搜索页，再读取并保存条件；关闭前后复核标签身份、地址、窗口和前台状态。现有 `/open` 接口保留兼容。
3. 在 `src/dashboard/pages/today.js` 与 `src/dashboard/view_models/today.js` 移除单独按钮，首次进入时自动显示读取状态；保留顶部统一的手动重读入口。更新浏览器旅程测试。
4. 运行智联定向测试、页面浏览器测试、完整离线门禁；在用户已登录 Edge 中只读核对真实路径和状态，不触发岗位扫描或沟通。

边界：只整理与 OfferGo 同窗的智联岗位搜索页；不触碰 BOSS、智联消息页、其他窗口或运行中的搜索任务。条件无法确认或前台状态变化时停止清理，不猜测标签身份。
