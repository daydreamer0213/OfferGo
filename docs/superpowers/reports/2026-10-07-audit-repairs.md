## 兼容与边界

没有引入运行依赖、修改 SQLite schema、改变招聘平台选择器或访问节奏。CLI 和 Agent stdio 协议保留；普通页面增加内部操作编号与编辑版本字段，以及两个只读生成结果查询入口，旧服务调用仍兼容。查询只确认本地结果，不调用模型、不访问平台。

Agent 复用的现有表要求每个 run 有独立简历文档，因此仅增加关联所需的文档快照，不重新分析、复制画像或复制文件。复用返回的 runId 对应本次 operationId。

没有取消发送确认、不确定结果停止或不自动重发的边界。发送成功后的资料整理失败，不会改变已确认的发送结果。

全部验收使用虚拟简历、受控模型和隔离数据库；Edge 实际操作的是当前代码运行的本地页面。没有真实平台发送、在线模型文案验收，也没有替换桌面安装版。

## 独立复查中补齐的边界

- “如果收到 offer，明天可以到岗”“预计明天到岗”保留条件和不确定说法，不能变成“现在可以到岗”。从已确认经历提取资料时也保留这些限定。通知、签合同之后的时间仍依赖相应事件。
- “从明天起每天下午都可以面试”是持续安排，不因开始日期过去就失效；“到某日期为止”仍按截止时间检查。原有确认有效期保留。
- 单条回答累计 501 个历史版本后，撤回不会漏掉最早版本。模型读取数量限制保留。
- 生成期间离开页面、后台完成后再返回，主动开始新一轮能产生新结果；即使旧结果已不在最近 30 条列表，也能按具体编号查询。查询失败保留编号和输入，不重复发起生成。

以上均有失败复现及修复后的行为检查；相对日期核对了实际回复模型输入，生成核对了实际 Edge、HTTP 与保存结果。
