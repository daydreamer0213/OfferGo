## 复核中补清的关键设计

1. 当前默认由模型通读完整JD与真实简历给投递价值，代码守本地边界、材料和来源；旧split评分不是默认主流程。
2. 慎投可进入候选审阅，但不充当足够主投/可投库存；等待资料与技术失败不冒充语义结论。
3. 主动清单确认后还需开始执行；消息回复确认则冻结内容并立即调度，两个流程分别解释。
4. BOSS批量主动联系与智联受控单岗验收边界分开；本地定制招呼稿不冒充批量已发送。
5. 启用投递简历不自动替换基础匹配资料，不自动更新平台附件。
6. 面试由产品先准备故事，用户核实；答完后明确点击生成复盘；训练回答须另行确认才能进入共享经历。
7. 体检展示即时进展与成熟条件分母，一条真实反馈可支持检查，但不证明总体根因。
8. 反馈卡不自动定位/改写简历，关联本地版本也不证明当时发送附件；比较轮次需满足具体样本和可比条件。
