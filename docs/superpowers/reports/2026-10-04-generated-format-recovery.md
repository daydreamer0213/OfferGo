# 三模块生成格式衔接修复

本轮针对第二次用户视角审查中确认的两处生成失败和一处展示问题。复现基线为 b5bc70f8eaffc0f6a758a67cc915542c0d49055d；不是对三模块重写。

## 问题与修复

1. 面试复盘的任务说明没有明确 outline 是字符串数组，文字提纲会导致实际页面报错。现已明确格式，并在原校验入口将字符串视为单项列表；继续检查长度、题号和其他报告字段。
2. 简历建议的编号只允许 S1/S2，但任务说明未告知模型。现由 application 为新生成建议分配内部顺序编号，再进入原有严格校验。模型提供的描述性或重复编号不会使有效内容全部失败；原文锚点、引用证据、数字、职责、重叠和条数校验保持。
3. 简历页将模型提供方式移入默认收起的“技术详情”，修改项显示普通序号。原有草稿编号、表单键和存储数据不变。主要绑定信息对应两列，窄屏仍沿用原有单列布局。
4. 截图复查确认，深色模式的简历结论误用了随主题变浅的文字色作为背景，白字对比度仅约1.11。沿用现有深色重点区域背景补齐该区域的主题覆盖；真实 Edge 检查深浅模式下标题与正文对比度均达到4.5以上。

没有增加运行依赖、模型重试、表结构或平台读写动作。用户的真实数据和已安装程序没有被替换。
