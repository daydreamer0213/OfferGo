# OfferGo v1.4.1

本版修复窗口高度较小时，左侧的“浅色模式／深色模式”按钮与“招聘平台”等导航项重叠的问题。

左侧导航保留内容所需高度，超出窗口时通过侧栏滚动查看；主题切换按钮与菜单分开排列。深浅两种模式、较矮桌面窗口和窄屏布局均加入浏览器回归检查，主题切换和导航点击保留。

## 下载与升级

普通 Windows 用户下载 **OfferGo-Setup-1.4.1.exe**，运行安装程序，然后从桌面或开始菜单的 **OfferGo 小狗图标**启动，无需使用 bat 文件。

同页提供 `OfferGo-Setup-1.4.1.exe.sha256` 完整性校验文件，以及给便携或 Agent 用户的 `OfferGo-v1.4.1-portable.zip`。升级沿用原程序目录；用户资料仍在 `%LOCALAPPDATA%\RoleFlow\Data`，专用 Edge 登录资料仍在 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`，本版不清空资料，也不改变数据库结构。

本版保留 v1.4.0 的功能与操作方式，主要变化见 [v1.4.0 发布说明](https://github.com/daydreamer0213/OfferGo/releases/tag/v1.4.0)。安装包包含固定版 Node.js 与依赖，不包含用户的 Key、简历、数据库、聊天记录或浏览器登录资料；安装器尚未代码签名。

## 验证范围

发布流程在标签对应的提交上执行全部 **195 项离线检查**，要求实际本地浏览器检查通过后才打包和发布。新增布局回归覆盖六种窗口尺寸和深浅两种模式，实际检查按钮与导航的占用区域、主题切换与导航点击。

本补丁不改变岗位读取、匹配、回复内容、面试出题或简历改写规则，没有执行真实 HR 消息、简历或投递发送。

公开状态和文件以 [v1.4.1 发布页](https://github.com/daydreamer0213/OfferGo/releases/tag/v1.4.1) 为准。
