# OfferGo v1.4.0

## 下载与安装

普通 Windows 用户下载 **OfferGo-Setup-1.4.0.exe**，运行安装程序，然后从桌面或开始菜单的 **OfferGo 小狗图标**启动。启动窗口会显示准备进度，完成后打开本地工作台；无需使用 bat 文件。

同页的 `OfferGo-Setup-1.4.0.exe.sha256` 用于核对安装包完整性。`OfferGo-v1.4.0-portable.zip` 提供给需要便携运行或交给 Agent 使用的用户；GitHub 自动生成的 Source code 压缩包不是安装程序。

## 本版重点

- 正式使用 OfferGo 名称和小狗图标，提供启动进度窗口、统一导航与深浅色模式。
- BOSS、智联可单独找岗，也可选择双平台同时找岗；复用各平台原有流程，同一平台内部仍按顺序读取。今日任务显示当前搜索条件，可重新读取；工作区整理重复的智联搜索页。
- 消息页统一整理两平台会话，展示来源、日期、岗位内容及回复草稿；过滤推广、拒绝和无需继续处理的消息。简历邀请与文字问题提供各自的确认操作，保留尚未处理的请求。
- 回复参考简历、已确认资料和真实经历，优先回答 HR 实际问题、讲清个人行动与方法。直接问协作或是否独立完成时，再准确说明相关范围，避免每次附加无关的责任声明。
- 简历工作室支持整份简历整理及针对单个岗位优化，保留正常结构、身份和真实经历，可预览、编辑、导出并启用版本。
- 面试训练支持通用能力与岗位专项问题，根据原回答追问、复盘和重练。经用户确认保存的真实经历，可供后续回复、简历优化和训练参考；不把 AI 评语当作用户事实，同一段回答不重复提出保存建议。
- Agent 可通过无界面 CLI 使用项目，不需要在前端配置 Key；未变化的简历可复用画像、匹配卡和方案。
- 补齐重复点击、失败恢复、父子任务状态、数据事务、诊断与模型设置缓存的回归检查，逐步明确应用与存储边界。

## 升级与资料

程序目录建议固定为 `D:\Apps\OfferGo`，升级默认沿用原目录。用户资料仍在 `%LOCALAPPDATA%\RoleFlow\Data`，专用 Edge 登录资料仍在 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`；本版沿用兼容目录，不清空资料。历史生成的草稿和报告保留，新生成内容使用本版规则。

安装包包含固定版 Node.js 与生产依赖，需要 Windows 10/11 和 Microsoft Edge。普通用户在工作台填写自己的模型服务 Key；Key、简历、数据库、聊天记录及浏览器登录资料均不进入发布包。安装器尚未代码签名。

## 验证范围

发布流程在标签对应的提交上执行全部 **195 项离线检查**，要求实际本地浏览器检查通过后才构建和发布。模型效果另以合成用户资料、真实模型输出和现有 Edge 页面验收：检查回复、简历启用、面试复盘、经历保存及后续回复复用。

上述内容不等于每一种生成结果都保证完美，也不等于本次向真实 HR 发送过消息或简历。本次效果验收没有执行真实对外发送；平台页面变化仍可能影响后续读取。沟通、回复、发送简历必须由用户确认具体目标，结果不明确时停止，不自动重发。
