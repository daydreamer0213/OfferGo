## 先分清两个版本

- **本次发布目标**：v1.4.0，安装文件 `OfferGo-Setup-1.4.0.exe`，产品名与小狗图标均为 OfferGo。只有公开 Release 非草稿且资产齐全、验证通过后才算发布完成；不会移动旧版标签或覆盖旧版文件。
- **历史公开版本**：v1.3.2 使用 RoleFlow 名称和旧图标，具体能力见[旧版说明](releases/v1.3.2.md)。当前源码已升级版本元数据到 1.4.0，包括双平台找岗、消息处理、共享资料、简历优化和面试训练；新标签必须指向最终发布提交。

## 当前代码怎样使用

- 在 v1.4.0 安装版里，普通用户从应用图标进入；源码或便携版也可启动工作台。用户可选择 BOSS、智联或两个平台，在模型与设置填写自己的 API Key；今日任务中可选单平台或“BOSS + 智联（同时）”。双平台调度各自原有流程，每个平台内部仍按其安全节奏读取。
- 把项目交给 Agent 时，外层 Agent 直接运行[无界面 CLI](agent-operation.md)，不打开工作台，也不在模型设置页填写 Agent Key。相同简历可复用画像、匹配卡和搜索方案；新一轮使用新的操作编号，重试同一命令才复用原编号。
- 安装版的数据库、简历、模型设置、日志和报告位于 `%LOCALAPPDATA%\RoleFlow\Data`；专用浏览器登录资料位于 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`。便携版和显式 `--data-root` 的位置以启动参数为准。换程序安装目录不等于重置安装版用户资料。
- 消息页会整理可读取的 BOSS、智联会话；识别出的简历邀请和文字草稿在本地页面提供相应的确认操作。对外发送必须由用户确认当前具体目标；页面身份、结果或安全状态不明确时停止，不自动重发。

## 三模块共用经历改造

当前源码已增加用户确认的面试经历，可在相关消息回复、后续训练与简历优化中参考；沟通资料页可修改或停止使用。普通在职、薪资、到岗等问题有资料就生成草稿，缺少资料在项目内逐项补齐。简历工作室默认支持无需 JD 的通用整理，也支持选择一份完整岗位调整。设计和早期验证见[三模块报告](superpowers/reports/2026-10-03-candidate-learning-three-modules.md)，本次纳入 v1.4.0 发布。
