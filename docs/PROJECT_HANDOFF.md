## 先分清两个版本

- **公开安装版**：v1.3.2 的下载文件仍叫 `RoleFlow-Setup-1.3.2.exe`，界面名称和图标仍是旧版。具体下载与该版本能力见 [v1.3.2 发布说明](releases/v1.3.2.md)。
- **当前仓库源码**：产品名为 OfferGo，包含较新的小狗图标、双平台同时找岗、搜索条件同步、智联重复搜索页整理、消息内确认发送等改动。`package.json` 仍写 1.3.2，**不能据此称这些新功能已经公开发布**；构建新安装器前需单独决定版本号和发布验收。

## 当前代码怎样使用

- 在当前源码构建出的安装版里，普通用户从应用图标进入；源码或便携版也可启动工作台。用户可选择 BOSS、智联或两个平台，在模型设置填写自己的 API Key；今日任务中可选单平台或“BOSS + 智联（同时）”。双平台调度各自原有流程，每个平台内部仍按其安全节奏读取。上述新功能不代表公开 v1.3.2 已具备。
- 把项目交给 Agent 时，外层 Agent 直接运行[无界面 CLI](agent-operation.md)，不打开工作台，也不在模型设置页填写 Agent Key。相同简历可复用画像、匹配卡和搜索方案；新一轮使用新的操作编号，重试同一命令才复用原编号。
- 安装版的数据库、简历、模型设置、日志和报告位于 `%LOCALAPPDATA%\RoleFlow\Data`；专用浏览器登录资料位于 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`。便携版和显式 `--data-root` 的位置以启动参数为准。换程序安装目录不等于重置安装版用户资料。
- 消息页会整理可读取的 BOSS、智联会话；识别出的简历邀请和文字草稿在本地页面提供相应的确认操作。对外发送必须由用户确认当前具体目标；页面身份、结果或安全状态不明确时停止，不自动重发。
