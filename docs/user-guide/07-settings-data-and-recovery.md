# 07 设置、资料与异常恢复

[返回指南首页](README.md) · [上一章：求职体检](06-job-search-review.md) · [下一章：版本与更多资料](08-status-and-documents.md)

这一章介绍怎样连接招聘平台与模型、资料保存在哪里，以及遇到问题时怎样继续使用。

## 1. 准备招聘平台

进入 **招聘平台**，选择 BOSS、智联或两个平台，保存后在 **OfferGo 专用 Edge（推荐）** 中登录。系统准备搜索与消息页面，页面显示就绪后即可继续。

第一次登录后会保存登录资料，之后可以复用。BOSS 的搜索页与沟通页放在同一个窗口，便于系统准确识别当前岗位和会话。

### 任务为什么有时会停一会儿

系统会分批读取岗位，穿插随机等待与阶段休息，并保存进度。页面显示等待或暂停时，可查看当前步骤和恢复时间；已取得的结果可以先看，剩余任务之后继续。

遇到登录失效或安全验证时，先在招聘平台处理，再回工作区重新检查。双平台分别安排任务，每个平台按自己的节奏处理。

## 2. 连接模型服务

模型服务用来理解简历、分析岗位和准备内容。**API Key** 是访问该服务的密钥。

1. 打开 **模型与设置**，选择预设或填写服务地址、模型名称和 API Key。
2. 点击 **测试连接并保存**。
3. 看到连接测试成功后，回到简历或找岗页面继续。

如果用了 **只保存参数** 或 **恢复推荐值**，再测试一次连接，让任务使用可连接的配置。

### 为什么有两项配置

| 配置 | 主要处理什么 |
| --- | --- |
| 深度分析 | 简历整理、回复和其他内容生成 |
| 批量筛选 | 岗位理解、匹配与重试 |

两项可共享服务商和密钥，模型参数分别设置，方便为内容生成与反复岗位分析选择合适配置。

更换用于匹配的模型或基础资料后，需要更新的岗位会进入待分析状态，按新依据重新处理。

## 3. 资料保存在哪里

简历、画像、方案、岗位、消息、草稿和训练记录保存在本机，方便重开页面后接着使用。

标准安装版的资料位置为：

| 内容 | 位置 |
| --- | --- |
| 求职资料、设置、日志和报告 | `%LOCALAPPDATA%\RoleFlow\Data` |
| 专用 Edge 登录资料 | `%LOCALAPPDATA%\RoleFlow\BrowserProfile` |

把路径粘贴到 Windows 文件资源管理器地址栏即可打开。RoleFlow 是沿用的旧目录名，升级会继续使用这些资料。

源码、便携版或 AI 助手也可以指定其他数据目录。想接着同一份记录使用时，选择同一目录。

### 哪些内容会发给模型

使用云模型时，会发送本次任务所需的材料。例如，生成回复会使用 HR 问题、岗位资料、脱敏简历和适用的确认资料；分析简历前，会先遮盖可识别的姓名、电话、邮箱等字段。

API Key 使用 Windows 当前用户的系统加密能力保存。换电脑或 Windows 用户后，重新配置 Key，并在专用 Edge 中重新登录招聘平台。

## 4. 遇到问题，怎样继续

| 看到的情况 | 处理步骤 |
| --- | --- |
| 工作台打不开 | 从 OfferGo 图标查看启动进度；就绪后打开显示的工作台地址 |
| 要求登录或安全验证 | 到对应平台完成操作，再回工作区重新检查 |
| 模型连接或请求失败 | 到模型设置测试对应配置，再回原任务继续 |
| 岗位等待补齐资料 | 找岗结果缺详情时，使用“补全岗位详情”；消息中的岗位待补齐时，回“消息与回复”重新同步 |
| 本轮已暂停 | 看暂停原因，条件恢复后点击“继续本轮” |
| 本轮已结束 | 查看已保存结果，后续另开一轮 |
| 发送结果不明确 | 到招聘平台打开对应会话，核对刚才的文字或简历是否已出现；核实前先不要重复发送。仍无法确认时，到“运行诊断”复制诊断信息求助 |
| 页面与指南不同 | 查看[版本与更多资料](08-status-and-documents.md)，核对所用入口 |

安装版默认地址为 `http://127.0.0.1:8787/`；开发预览以当次启动显示的地址为准。

### 暂停与结束怎么选

稍后还想接着做，用 **暂停本轮**。系统完成当前一步的保存后显示已暂停，之后沿原轮继续。

暂停期间改过平台条件时，按页面选择继续原条件，或按新条件重新开始。

决定关闭这一轮，用 **结束本轮… → 确认结束本轮**。已保存结果保留，后续从新一轮开始。

因模型超时或配置问题自动暂停时，按 **测试批量模型连接 → 测试连接并保存 → 回原轮 → 继续本轮** 处理。普通手动暂停可在核对状态后继续。

## 5. 需要排查或求助时

进入 **运行诊断**，可以查看最近的警告和错误：

- **查找排错编号**：粘贴出错页面给出的编号，找到这次请求的记录。
- **复制诊断信息**：复制版本和运行状态摘要，便于求助；摘要已排除简历正文、岗位内容和登录信息。
- **打开日志文件夹**：查看本机详细日志。

求助时先提供页面提示与诊断摘要即可。任务中断后，已经保存的资料和进度继续保留，可以回到原任务处理剩余部分。
