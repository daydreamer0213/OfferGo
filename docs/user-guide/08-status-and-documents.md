# 08 版本与更多资料

## 1. 为什么我的页面和指南不完全一样

这份指南介绍当前开发版的功能。2026 年 10 月 16 日整理时，公开安装版为 **v1.4.1**，后续改进主要在开发版和本地预览中使用。

| 后续改进 | 对使用有什么帮助 |
| --- | --- |
| 完整 JD 的工作判断 | 结合岗位主要工作和你的实际经历解释投递价值 |
| 慎投进入候选清单 | 保留有相关经历、但存在差距的尝试机会 |
| 面试故事准备 | 根据简历先生成初稿，修改后直接选故事练习 |
| 简历分区编辑 | 沿原章节与项目展开修改，仍保存成完整简历 |
| 具体反馈复盘 | 从 HR 原话和已有回答出发，指出值得检查的表达 |

如果页面上找不到某个新入口，先核对自己使用的是安装版还是开发预览。开发版仍在继续检查真实使用效果和连续运行体验，进展记录在[项目验收清单](../superpowers/plans/2026-10-09-four-step-acceptance.md)。

## 2. 安装、更新与日常使用

- **安装版怎样启动和更新：** 看[安装版使用说明](../installed-user-guide.md)。
- **下载正式版本：** 打开[GitHub 发布页](https://github.com/daydreamer0213/OfferGo/releases)，选择安装器。
- **了解某版改了什么：** 查看对应版本说明，例如 [v1.4.1](../releases/v1.4.1.md)。
- **遇到运行问题：** 先看[设置与恢复](07-settings-data-and-recovery.md)，需要进一步排查时再查[运维说明](../operations.md)。
