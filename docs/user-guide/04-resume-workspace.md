# 04 简历工作室：沿原简历结构，把工作写清楚

[返回指南首页](README.md) · [上一章：沟通、消息与进展](03-communication-and-progress.md) · [下一章：面试准备与训练](05-interview.md)

简历工作室帮助你把实际工作写得更具体、更好读。它先给完整草稿，你可以按原简历的章节和项目继续修改，再保存或导出。

## 1. 这次想怎样整理

进入 **简历工作室**，选择参考简历和模式：

| 模式 | 适用情境 | 怎样处理 |
| --- | --- | --- |
| 整理我的简历 | 项目写得散、贡献不清、整体不易读 | 从已有经历整理结构、工作内容和结果 |
| 为这份岗位调整 | 想争取某一份岗位 | 选完整 JD，突出与它相关的真实经历 |

例如，目标岗位更看重接口开发，系统会把你的接口实现、设计考虑和相关成果讲得更清楚。通用整理则着重改善整份简历的表达。

## 2. 完整草稿是怎样整理出来的

1. **读取材料。** 使用所选原简历和你确认过的相关经历；岗位模式再加入目标 JD。
2. **找到值得改的地方。** 看工作、本人贡献、结果和段落结构是否清楚，保留原本合适的内容。
3. **对照材料修改。** 新写法需要能对应到原简历或确认过的经历，尤其是数字、技能和职责。
4. **组成完整草稿。** 把修改放回全文，展示改动说明，方便你对照阅读和编辑。

这些步骤让“为什么改”和“改成什么”对应起来。例如，原文只写“参与系统开发”，修改说明可以指出缺少本人分工，并把已有材料里的接口、校验或测试工作展开。

## 3. 直接到要改的章节

编辑器沿用原简历的标题和顺序，项目经历里能识别的项目也会单独展开。常见修改可以直接在 **项目经历 → 某个项目** 或 **技能** 部分完成。

这些分区共同组成同一份全文，保存和导出时会汇总在一起。想新增章节、调整标题或一次通读，可使用 **编辑全文与章节标题**；结构识别不清楚时，也能从全文继续改。

编辑重点是文字内容。需要输出时，可下载文字版，或通过打印视图保存 PDF；原 Word、PDF 的字体和版式可在后续排版时调整。

## 4. 看一个修改例子

假设原稿写的是：

> 参与库存系统开发，使用 Java、MySQL。

已有材料说明本人做了入库接口、重复单号校验和回归用例，就可以展开为：

> 负责入库接口与重复单号校验，并补充重复提交场景的回归用例，检查同一单据是否会重复生成库存流水。

新写法讲清了本人工作、针对的问题和检查方法。若还有实际验证结果，可以接着补上。定性成果也可以写清楚，例如“重复提交能被识别并返回已有处理结果”，不必每段都凑一个百分比。

## 5. 保存、导出与启用

| 操作 | 结果 |
| --- | --- |
| 自动保存 / 保存草稿 | 保存当前修改，稍后可以继续编辑 |
| 复制当前全文 | 复制完整文字 |
| 下载文字版 | 导出当前文字内容 |
| 打印 / 保存 PDF | 打开打印视图，打印或保存 PDF |
| 启用为新版本 | 创建本地可用版本，保留原简历和历史 |
| 以此版本继续编辑 | 从已启用版本创建新的编辑副本 |

启用前，系统会检查正文、联系方式、占位内容和部分新增表述的依据。你再通读分工、数字与结果，确认表达符合实际后启用。

启用后的稿件保留当时内容。后续要修改，就创建编辑副本，方便回看每次启用时的简历内容。

### 修改后接下来做什么

- **要在招聘平台发送：** 先到对应平台更新简历或附件，再处理发送。
- **新增经历希望用于找岗：** 到资料页更新并确认匹配卡，让找岗使用新的基础资料。
- **只想换一种投递表达：** 在简历工作室保存或启用即可，原匹配依据继续沿用。

保存失败或两页同时编辑时，页面会提供恢复或冲突提示。先保留当前文字，再合并两边修改。

## 6. 从反馈与面试中补充内容

求职体检建议“先核对项目中的本人职责”时，可点击 **检查项目经历描述** 进入简历工作室。选择参考简历；需要针对岗位调整时，再选目标岗位，修改对应项目。

面试练习中补清的真实经历，经 **确认并保存这段经历** 后，也能作为后续简历整理的材料。这样，准备面试时想清楚的分工、方法和结果，可以继续用于简历。
