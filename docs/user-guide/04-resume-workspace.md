# 04 简历工作室：沿原简历结构，把真实工作写清楚

[返回指南首页](README.md) · [上一章：沟通、消息与进展](03-communication-and-progress.md) · [下一章：面试准备与训练](05-interview.md)

简历工作室负责整理与修改简历表达：让读者更容易看懂你做过什么、本人负责什么、工作有什么结果。它不为追求“看起来更强”而增加不存在的经历。

## 1. 先选择这次为什么改

进入 **简历工作室**，选择一份参考简历，再选择模式：

| 模式 | 适用情境 | 使用的岗位资料 |
| --- | --- | --- |
| 整理我的简历 | 项目写得散、贡献不清、整体不易读 | 不需要先找岗位 |
| 为这份岗位调整 | 某一份岗位值得争取，想突出真实相关经历 | 使用所选一份资料完整的 JD |

岗位调整不是把 JD 技能表复制进简历。例如，JD 要求架构经验，但你只负责接口实现，就应突出接口工作与相关设计考虑，不能改成主导架构。

两种模式都先交付完整草稿。你不必先手工改好，才能让系统提供帮助。

## 2. 从参考简历到草稿，程序做了什么

1. **确定材料范围。** 读取所选源简历、适用的已确认资料；岗位模式再读取该岗位完整 JD。
2. **为事实建立来源。** 把可以引用的简历内容、已确认经历等组织成证据目录，后续修改需要能对应回真实材料。
3. **让模型提出局部修改。** 重点是工作内容、本人贡献、结果、结构与可读性；原本合适的段落可以保留，不强制为了“优化”全部改写。
4. **检查并组成完整草稿。** 程序核对引用和修改位置，检查新增数字、技能或职责等是否有依据，再把修改应用到原稿。
5. **供用户检查、编辑和决定是否启用。** 自动检查能挡住部分错误，但不能替代本人确认每句事实。

系统还会展示修改说明和依据，帮助你理解为什么动这一处。你后来手工修改的文字，不能因此理解成系统已经重新逐句审核过。

## 3. 为什么按原简历章节编辑

常见修改发生在某段项目、工作经历或技能描述。把所有内容挤进一个输入框，会很难找到该改的位置；把简历另分成“基础资料”“常用资料”，又破坏了原来的组织方式。

当前编辑器沿用原简历的章节和顺序。能识别出明确项目标题时，项目经历还能按项目展开。你可以直接到“项目经历 → 某个项目”修改，也可以用 **编辑全文与章节标题** 调整整体文字、标题或新增章节。

**分区是同一份全文的不同编辑视图。** 保存时仍汇总成完整简历，不会把几个输入区存成彼此脱节的材料。识别不清楚的简历保留全文入口，不要求用户先改成统一模板。

这是一套文字内容编辑器，不是原 PDF 或 Word 的版式设计器。原附件的字体、表格与分页，不属于分区文字编辑的保真承诺。

## 4. 一个具体修改例子

虚构原稿：

> 参与库存系统开发，使用 Java、MySQL。

若已有真实材料支持本人做了入库接口、重复单号校验和回归用例，可以整理为：

> 负责入库接口与重复单号校验，并补充重复提交场景的回归用例，检查同一单据是否会重复生成库存流水。

这次修改让人知道“本人做了什么、针对什么问题、怎样检查”。如果没有实际记录支持，就不能继续写成“主导系统架构，吞吐提升 50%”。

有真实定性结果就保留定性结果，不要求每段强行出现漂亮数字；只有目标、还没有验证结果时，也要如实区分。

## 5. 保存、导出、启用分别发生什么

| 操作 | 实际结果 |
| --- | --- |
| 自动保存 / 保存草稿 | 更新本地可编辑草稿，不调用模型重新生成 |
| 复制当前全文 | 复制此时汇总后的完整文字 |
| 下载文字版 | 导出当前文字内容 |
| 打印 / 保存 PDF | 打开打印视图，通过浏览器打印或保存 PDF |
| 启用为新版本 | 校验后创建本地可用简历版本，保留来源和历史 |
| 以此版本继续编辑 | 从已启用稿创建新的编辑副本 |

草稿可以先导出、核对，不必立即启用。保存失败或两个页面同时修改时，页面会提供输入恢复或冲突提示；先保留当前文字再合并，不让旧页面无声覆盖新稿。

### 启用前检查什么

程序检查正文、占位内容、原姓名联系方式是否丢失，以及部分新增数字、技能和职责的依据。它是有限的保护，不是对所有语义事实的认证。

启用成功后，生成本地简历记录与可用版本，登记相应简历策略变化；原简历和历史保留。已启用的这份草稿只读，后续修改用副本，便于追溯当时用了什么内容。

**启用本地版本不会自动更新 BOSS、智联附件，也不会自动发送或投递。** 平台附件和具体发送仍需另行处理。

启用投递版本也不自动替换匹配卡绑定的基础简历与画像。若新增真实经历需要改变找岗判断，应到资料流程更新并确认对应依据；不能只改投递稿，就假定系统已经按新经历重新找岗。

## 6. 与求职体检和面试资料怎样配合

求职体检可能提醒你检查某种表达，例如本人职责不清。你可以从提醒进入简历工作室，核对原简历，选择适当模式并修改相关章节。

目前这个跳转不会自动选定原岗位、定位到某段，也不会把 HR 原话自动注入简历生成。具体反馈提供检查方向，真正采用哪条事实、改哪份简历仍要明确选择。

在面试训练中，另行确认保存的真实经历可以作为后续优化材料。准备故事草稿、练习中的假设方案和未经确认的示范答案，不会自动当成新经历写入简历。
