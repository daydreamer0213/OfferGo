## 启动与打开工作台

1. 安装完成后，双击桌面或开始菜单中的 **OfferGo** 图标。安装版不需要运行 `Install.bat` 或 `Start.bat`，也不需要安装 Edge Control。
2. 启动窗口会显示检查、准备浏览器和工作台的进度。准备完成后打开本地工作台；它只在你的电脑上运行。若浏览器未自动显示页面，先确认启动窗口已经就绪，再访问 `http://127.0.0.1:8787/`。
3. 日后仍从 OfferGo 图标启动。开始菜单的 **OfferGo 使用说明** 会打开这份文件；它位于程序目录下的 `README.md`。若 Windows 没有 Markdown 阅读器，可以右键文件，选择“打开方式”→“记事本”阅读。

## 首次使用

1. 打开 **招聘平台**，选择 BOSS、智联或两个平台。在 OfferGo 专用 Edge 中登录所选平台，再按工作区提示检查页面是否就绪。BOSS 使用同一窗口中的 `BOSS-SEARCH` 和 `BOSS-COMMUNICATION` 页面；不要启动多个扫描窗口。
2. 打开 **模型与设置**，填写你选用的模型服务 API Key，点击 **测试连接并保存**。看到连接验证及保存成功后继续。向云模型发送简历或岗位资料前，先阅读页面提示。
3. 打开 **简历工作室**，上传 TXT、MD、DOCX、PDF 简历或粘贴文本。检查系统整理出的本人信息和经历；扫描件无法提取时按提示粘贴文本，不需要重新填写整份简历。
4. 核对匹配偏好和搜索方案，选择求职城市，调整需要修改的薪资、经验及关键词并保存。进入 **今日任务**，检查所选平台当前搜索条件；不一致时先调整平台页面，再重新读取条件。

完成后应能看到已保存的简历、画像和搜索方案。登录或保存方案不会自动扫描或发送消息。更详细的首次使用步骤见[首次使用说明](docs/onboarding_workflow.md)。

## 日常找岗与回复

1. 在 **今日任务** 选择方案和平台，启动一轮找岗。等待只读采集和分析完成，在 **发现岗位** 或 **岗位记录** 查看职责、本人经历依据和待处理项。
2. 要主动联系时，先检查并确认具体岗位清单，再点击 **开始沟通**。分析完成不会自动开始联系。不要为赶进度并行操作招聘页面。
3. 在 **消息与回复** 点击 **同步最新消息**。查看 HR 原文及下一步；有回复草稿时先核对事实并修改，再对当前目标点击 **确认发送**。缺少本人事实时先补充。简历邀请有独立确认操作，不会因你查看消息就发送。
4. 在 **简历工作室** 可以整理整份简历或针对岗位生成草稿，检查全文后再保存或启用新版本；启用本地简历不会更新招聘平台附件。在 **面试训练** 中确认保存的真实经历才会供后续参考。

完整的找岗、暂停和确认流程见[每日使用与沟通说明](docs/daily_workflow.md)。结果统计反映已有记录，不代表平台实时状态或增长因果；见[结果统计说明](docs/outcome_analytics.md)。

## 中断与恢复

- 启动失败：在启动窗口点击 **打开诊断信息**，保留错误提示，再按[排错说明](docs/operations.md)检查。不要删除资料目录来尝试修复。
- 登录失效、验证页或岗位身份不符：先在平台完成登录或恢复页面，再检查工作区就绪状态。系统停止时不要连续重复点击。
- 本轮已暂停：确认暂停原因。模型连接或超时问题先到 **模型与设置** 测试并保存连接，再返回原轮点击 **继续本轮**。正常手动暂停可以在核对状态后继续。
- 想结束本轮：**结束本轮…** 还需要一次明确确认；已保存结果会保留，但结束后的轮次不能继续。想稍后接着做，应使用 **暂停本轮**。
- 发送结果不明确：先到原平台查看真实结果，勿直接再发一次。系统不会自动重发；不能把“未能确认”当作发送失败。
- 工作流出现关联异常：停止该轮并查看 **运行诊断**，不要绕过提示。各项含义见[流程体检说明](docs/workflow_health.md)。

## 更新与资料

1. 使用明确版本的正式安装器更新，安装目录建议固定为例如 `D:\Apps\OfferGo`；升级沿用已有安装目录。单纯更换程序目录不会创建全新的求职资料。
2. 当前 Windows 用户的数据库、简历、模型设置、日志和报告保存在 `%LOCALAPPDATA%\RoleFlow\Data`；专用 Edge 登录资料保存在 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`。名称沿用 RoleFlow 是兼容行为，不代表资料丢失。
3. 更新不会要求把浏览器登录资料复制进安装目录。换电脑时重新登录招聘平台；不要直接复制登录资料。卸载默认保留用户资料，删除浏览器登录资料需要独立确认。

本地测试构建并不等于正式发布。当前源码和公开旧版的交付区别、隐私范围见[安装包与资料边界](docs/release_boundary.md)。
